# 上肢3D解剖ラボ（Upper Limb 3D Anatomy Lab）

スマートフォン対応の上肢骨格・筋肉・腱を観察する教育用Webアプリ。動作と形態は**解剖学的に未検証の近似を含み、臨床用・診断用ではありません**。

## v0.59：背部筋と付着近似の改善

僧帽筋3区分と広背筋をBodyParts3Dメッシュ化。前鋸筋の肋骨近接領域を固定し、肩甲骨内側縁候補へ追従。GPUの胸郭方向変位抑制を追加。深層筋の付着候補を更新。厳密な衝突・筋体積保存は未実装。詳細は [BACK_V059](./docs/BACK_V059.md)。

## v0.58：深層筋と肩の2方向操作

BodyParts3Dの大・小菱形筋、肩甲挙筋、前鋸筋、肩甲下筋を読み込み、左右鏡映・GPU二点補間で変形。旧深層筋の板状モデルを廃止。肩長押しの上下・左右ドラッグで挙上角と挙上面を操作。詳細は [DEEP_V058](./docs/DEEP_V058.md)。

## v0.57.2：操作性と前方挙上

実骨の前方挙上を -Z に修正し、180°で挙上面ごとの回転を連続化。肩甲帯前方移動は固定パラメータの模式モデル。両腕の前ならえ・T字・バンザイ・基本肢位プリセットを追加。操作中は描画倍率を最大0.85、停止後は最大2に復帰（自動／軽量／高精細）。関節入力をフレーム単位に集約し、操作終了時に画面外の場合のみフィットするオプションを追加。実機速度・臨床的運動精度は未検証。[詳細](./docs/MOTION_V0572.md)

## v0.57.1：胸郭接続の補完

第1〜7肋軟骨の左右14メッシュ、C2–T11の下位椎間板17メッシュを追加（合計79）。肋軟骨と椎間板を異なる色で表示。旧BP24/28を個別非表示可能。新規グループ取得失敗時も既存胸郭48部位を保持し、未取得グループのみ再試行。軟骨面交差候補・第7肋軟骨の境界箱・SC/AC推定中心から骨頂点までの距離の監査を追加。医学的接触精度は未検証。[詳細](./docs/THORAX_V0571.md)

## v0.57：胸郭・脊椎の精密化

BodyParts3Dの同一アトラスから左右肋骨24、頸胸椎19、胸骨3、肋軟骨2（計48メッシュ）を個別取得。元の共有座標を保持し、全取得成功時のみ胸郭全体を置換。未取得時やWebGL非対応時は旧近似を明記。背部筋は旧形状のまま初期OFF。出典・部位表・制約は [THORAX_V057](./docs/THORAX_V057.md)。

## v0.56：両上肢・胸郭・背部

左右独立の関節操作、右上の左右切替、姿勢コピー、両腕・胸郭・背部筋の個別表示を追加。左上肢は右の既存実骨・筋腱形状を鏡映し、左右それぞれ別の可動状態を保持します。胸郭・胸骨・頸胸椎および僧帽筋、菱形筋、肩甲挙筋、広背筋、前鋸筋は模式メッシュです。実測形態・骨接触・筋張力・胸郭運動は未検証。

## 主な機能

BodyParts3Dの肩甲骨、鎖骨、上腕骨、橈骨、尺骨、および右手の骨27個を利用した表示（データ取得不可時は近似形状）。肘屈伸・肩挙上・前腕回内外・手指の教育用の概形操作を提供します。筋肉・腱は手作業の推定パスです。

v0.55では棘上筋・棘下筋・小円筋・大円筋の**輪郭を筋ごとの曲線と厚み分布で再構成**し、直線的な板状表現を改善。前部／後部の筋束分離や実測腱付着点の再現ではありません。小円筋までの3筋は回旋筋腱板、大円筋は含まれません。**肩甲下筋は未実装**。

## 開発・テスト

HTML/JSのみで起動しますが、実骨メッシュを表示するにはオンライン通信が必要です。

```bash
node tests/upper-body-v056.mjs
node tests/scapular-muscles-v055.mjs
node tests/scapular-muscles-v054.mjs
node tests/scapular-muscles-v053.mjs
node tests/scapular-muscles-v051.mjs
node tests/medical-anatomy-audit.mjs
node tests/shoulder-kinematics-v050.mjs
```

テスト通過は3Dの骨貫通・生体組織の滑走・医学的な位置精度を保証しません。実骨データ上の筋の起始・停止・腱経路の照合と専門家レビューが必要です。

医学生の自習用途としての形態的正確性は未達です。用語や一般的な起始・停止・作用は文献照合済みですが、**筋腹・腱の3D数値は測定に基づかない推定**です。BodyParts3Dデータの使用許諾・クレジットはHTML本文に記載。

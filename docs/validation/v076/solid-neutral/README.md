# 同一原型・骨姿勢による中立位の比較（未採用）

2026-11-27。三角筋中部14,841頂点・29,678面の同じ修復sourceを、現共通エンジンの曲線方式と新分割の体積参照で比較した。参照は原型の骨格位置から現在の基本肢位へ固定領域を移した静的解であり、筋活動の再現ではない。**公開v075との比較、挙上時の改善証明、全筋の移行完了ではない。**

最終骨a/bの位置・回転・rest、固定領域、カメラ、表示設定を機械照合。全筋表示と診断用の三角筋中部のみ表示、それぞれ正面・側面・背面の6組12画像。ページ例外0、WebGLエラー0。筋を隠すことを改修の合格とは扱わず、全筋表示を同時に保存した。画像はブラウザそのまま、パネルは縮小配置と外側のラベルのみ。

最大値だけ改善しても、最小辺／面積は悪化しており採用の根拠にしない。Float32前の参照固定端の骨姿勢誤差は丸め誤差のみ。四面体による局所J・Float32反転監査・内部分割間の差は[体積参照](../../../VOLUMETRIC_REFERENCE_V076.md)を読む。骨接触・自己交差・高挙上・実機性能は合格にしていない。

# v0.54 肩甲骨周囲筋の再調整・検証メモ

日付：2026-11-24  
実機入力：v0.53（iPhone）の複数方向のスクリーンショット  
目標：**医学部生が自主学習で使える正確性**  
判定：**現状未達。3D骨格は実骨データ、筋肉・腱は独自の推定形状。**

## スクリーンショットの問題

1. 肩甲骨下部に赤い膜状の広い面が残る。特に腕を横に向けた姿勢で縁が尖って見える。
2. 上腕骨頭近くの腱・筋肉が重なり、丸まりや不自然な帯・ループに見える。
3. 小円筋・大円筋まで棘上筋・棘下筋と同じ扇状の表示方法だった。筋ごとの形態差が不足していた。
4. これまでの診断は数値的シームと2D投影が主で、骨への実際の接触・付着面・腱滑走の確認ではなかった。

## v0.54の変更

- **筋ごとの幅**：棘上筋・棘下筋は広がる扇状、**小円筋・大円筋は細長い帯状**として表示範囲を狭める。無根拠な滑らかな巨大シートを減らす。
- **筋腹の厚み**：一律の厚い板ではなく、中心が厚く周囲が薄い浅い形状に調整。肩甲骨の背面への近接投影は継続。
- **筋腱移行部**：前版より手前で筋腹表示から腱へ切り替える。肩甲骨の縁から上腕骨停止部への区間は**なめらかな二次ベジェ曲線**とし、停止に向かって細く収束する。
- **除去した処理**：v0.53の**球体に見立てた上腕骨頭から強制的に押し出す処理**を停止。姿勢によって不自然な折れが生じる可能性があった。
- **復旧可能性**：v0.53の公開前版を `archive/v0.53-before-review` に保存。

## 検証

- `node tests/scapular-muscles-v054.mjs`：合成した表裏2面の肩甲骨に対し21姿勢×4筋。円筋の相対幅、骨後面からの距離、筋腱シーム、腱経路の過大な点間ジャンプ、ON/OFF再生成。
- `node tests/medical-anatomy-audit.mjs` と既存肩帯運動回帰テスト。
- **実機スクリーンショットでの最終見た目確認は、v0.54公開後に必要。**
- **解剖学的・医学的な検証は完了していない**：特に筋膜・付着面・上腕骨頭との衝突、運動中の腱滑走が未検証。

## 解剖学上の根拠と注意

棘下筋は肩甲棘の下の広い棘下窩を占める三角形の筋。一方、小円筋は肩甲骨外側縁から起こる細長い筋。大円筋は肩甲骨下角と外側縁の下部から起こり、**回旋筋腱板には含めない**。これらの解剖学的違いを**形態クラスの設計指針**に使ったが、実測筋厚や起始停止パッチの個体差を再現したわけではない。

## 残課題

1. BodyParts3Dの骨面上で棘上窩・棘下窩・外側縁・下角・上腕骨停止部の**付着領域の正しいポリゴン抽出**。
2. 筋膜・腱・関節包・骨頭の**3D交差判定**と腱の包み込み経路の再構築。
3. 肩甲下筋（回旋筋腱板4筋目）の追加と、筋肉の層ごとの遮蔽・透過表示。
4. 全方向のiPhone表示・複数姿勢での医学生／解剖専門家レビュー。
5. 個々の筋の実測形状・筋束方向の典拠を整備し、「検証済み」「推定」「未実装」を明確に分離する。

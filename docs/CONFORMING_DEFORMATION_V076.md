# 原型表面を保つ制御四面体変形（継続中・未採用）

2026-11-27。製品への統合・公開は未完了。筋力・活動率はnull。元の解剖表面を制御四面体へ埋め込む軽量化を実装したが、接触・付着定義・180°の収束が残る。

## 分割と変形の整合

元の三角形が制御セルをまたぐまま頂点だけを補間すると、内部セルのJが正でも表示三角形が折り返せる。`conforming_surface.py`は元三角形を制御四面体の境界で分割する。元の全頂点を移動せず保持し、新頂点は元三角形上の重心座標で作る。各表示三角形が1つのアフィンセルに入り、正のセルJから局所的な向きの保存が得られる。非局所自己交差は別途必要。

三角筋中部：元14,841点／29,678面→29,873点／59,742面。元三角形ごとの面積和の相対誤差最大4.24e−13、共有点の一致誤差最大8.42e−14mm、全89,613辺の面数は2。穴埋め・外形変更・元頂点の削減はしていない。単体試験では非一様な正J変形の面法線がセルのcofactor写像に一致することも確認。

制御格子18mmは数値近似の解像度で、解剖寸法ではない。材料積分は元の正体積四面体の4点正求積をセルへ分配した近似。空セルの弱い数値正則化を別記し、筋の質量と混同しない。12mm等との比較が必要。

## 解法

正規化等容ひずみ＋log体積項の厳密な応力微分を追加。最適化の局所Hessianの負固有値だけを0へ射影し、目的関数・固定端・J拒否・停止0.001mmを維持。応力の独立有限差分、共有要素組立、剛体回転の共変性を試験。回転の零モードを無視していた近似SPDより収束を改善した。論文の物性・実時間性能を再現したとはしない。

## 実骨で見つかった境界条件の問題

90°外転の全29,873表面点を同じアトラスの閉鎖肩甲骨・上腕骨で検査した。肩甲骨への最大深さ増加1.34110mm、上腕骨へ4.01042mm。元からある交差を点ごとに区別した。上腕骨内の全体最大深さは基準と同じ4.0753mmだが、別の頂点が新規に入るため、全体最大だけでは検出できない。

上腕骨への最悪点は元の頂点12473、旧起始ウェイト0の固定点。筋変形だけでは動かせない。旧起始392点の肩甲骨への距離は中央値6.683mm、最大19.724mm、最悪点自身10.123mm。322点が2mmより遠い。**この2mmは調査用集計であり、付着の合否・削除閾値ではない。** 旧固定ラベルが骨の実測付着ではなく筋腹／腱膜端の推定も含むことを再確認した。問題点だけの固定解除や閾値緩和で解決扱いにしない。

## 次の作業

1. 固定ラベルを解剖学的な骨付着・腱／腱膜端・単なる骨接触から区別し、骨ローカルの定義データを再照合する。広い付着を単点へ潰さない。
2. 共通の接触拘束を筋の自由領域へ加え、固定領域に矛盾があれば骨格・定義を監査する。平均値や全体積だけで採用しない。
3. 内外旋と挙上面の定義を原著の座標系で検証する。GHのEuler/Cardan系列を取り違えて回旋曲線を加算しない。
4. 解像度、全角度順逆、左右・頸部、実骨交差、GPU・実機性能、同条件画像を確認してから製品へ統合する。

## 参照と取得状況

[Ludewig2009本文・Fig5D](https://pmc.ncbi.nlm.nih.gov/articles/PMC2657311/)を再確認。研究の肩甲骨軸はTS→ACで、現構造フレームのTS→AAと同一ではない。群平均・誘導された動作であり、アトラス個体の絶対角へそのまま足せない。GH座標系列の照合は継続中。

[Seth2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6856649/)は筋経路と巻付面の設計の参考。原配布SimTKは今回の直接取得にログインが必要だった。同著者らによる2023年研究の[公開モデルv1.1](https://github.com/ComputationalBiomechanicsLab/rmr-solver/tree/v1.1/OpenSim%20Models)は取得可能で、モデルデータはCC BY 4.0。まだBodyParts3Dへの座標登録・付着の移植をしていない。力・活動推定を導入したとはしない。

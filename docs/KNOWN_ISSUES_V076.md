# v0.76 既知の問題 — 根本改修未完了

2026-11-27更新。main／公開サイトはv0.75.0のまま。GitHubや実行環境の利用不可による保留ではなく、筋の形状が未達であるため公開を保留している。試験成功と人体形状・医学的正確性の合格を区別する。

1. **共通変形の局所破綻。** 元の曲線／材料チャートには折返し・横断幅の退化がある。直接の近接投影・厚み補正・DQSだけの案は全体を合格にしなかった。新ARAPグラフも全体体積を保てる一方で面方向の警告が残り、製品へ採用していない。[詳細と反例](MUSCLE_DEFORMATION_V076.md)。
2. **原型と固定領域。** クラスタリングと逆向き面の片方除去が閉鎖原型を開いていた。再構築した大胸筋・三角筋7区分は体積を評価できるが、現在の製品パーサーは未移行。多数区分で固定領域の片端または両端が欠けていた。source骨面に基づく追加候補は未採用の推定である。元から開いた面や未取得腱膜を勝手に閉じたり実測付着と呼んだりしない。
3. **過去の最大変位を最新値と混同しない。** 旧v0.73の53.698mmは僧帽筋下部6696、外転120→123°。57e3530の21.165mmは肩甲挙筋78、前方90→93°。最新骨格と保存済みbindingの個別計算では各1.310mm、2.135mmとなるが、入力を固定した診断であり現アプリ全筋の最大値ではない。最新の実アプリ掃引では僧帽筋上部168、外転3→6°が最大サンプル19.1166mm。細分で減るが、大きい連続変形が残る。
4. **骨格の正しさは接触0だけで決めない。** source肋骨の包絡拘束を追加し、543姿勢の全肩甲骨頂点で肋骨内部0、21姿勢の双方の辺・面交差0を確認した。共面重なり、他の全骨面、軟骨・関節包・靱帯は未検証。SC/AC/STの最終角とpriorからの変化も記録し、解剖学的姿勢を監査する。[骨格記録](BONE_CONTACT_V076.md)。
5. **運動の近似範囲。** SC/ACはLudewig2009の群平均図の読み取り近似。120°超は文献端を連続に延長する教育用操作域であり、全範囲の生理学的成立を保証しない。任意の軸回旋に伴うSC/AC連動、機能的中心、個体差・体幹代償は未同定。共有ピボット誤差0も関節面の正しさの証明ではない。
6. **全身への移行・接触。** 17アトラス区分と頸部6メッシュ以外にも既存筋・腱のアダプターが残る。元の解剖表面と操作を保持し、定義データ・滑走経路へ移す必要がある。筋膜・隣接筋の動的滑走、体積ヤコビアン、graph方式のGPU整合は未検証。結果のnullを0件と扱わない。
7. **法線と性能。** 現GPU法線は局所近似。graphの全source体積投影は参照計算が重く、そのまま製品へ組み込めない。スマートフォン／Safari実機30fps、実タッチ、全手指・弓道4段階の実機監査は未検証。SwiftShaderやNodeの時間を実機fpsへ換算しない。
8. **頸椎。** 左右回旋・直接操作・左右の腕との独立性は維持する。分配、中心、椎間板、頸部筋付着は教育用近似で、±75°操作の試験は臨床可動域の証明ではない。活動率・筋力はnullのまま。

This experiment represents rigid scapular/clavicular correction as deterministic continuous joint-coordinate interpolation of solver results on a regular grid (15° elevation, 15° plane, 45° axial). These are numerical experimental resolution choices, not physiological or acceptance thresholds. Uses hemisphere-normalized quaternion corrections relative to the exact commanded base rotation; SC and AC rigid linkage and commanded humerus unchanged. No temporal filtering, thickness adjustment, muscle coefficients or mesh modification. Field nodes cached by guide geometry; not yet optimized for phones. A field pose is NOT guaranteed to satisfy contact constraints; hard and regional feasibility are audited at each query and across 245 combinations, with violations explicitly recorded. No fallback snap on failed audit. Do not deploy if quality, contact, performance or existing tests fail. Need compare 141–144° as well as earlier outliers with exact cameras and check full sweep. An experimental field is not a clinical model.

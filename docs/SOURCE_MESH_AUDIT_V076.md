# 原型メッシュと付着データの監査（進行中）

2026-11-27。下記の筋データの再構築・変形候補は検証中であり、製品の既定変形に統合していない。骨格の追加拘束は[BONE_CONTACT_V076.md](BONE_CONTACT_V076.md)。

## 発見した問題

1. 頂点クラスタリングが面の閉鎖性と小面積三角形の品質を損ねる。さらに、重なった逆向き三角形の片方だけを残す旧処理が閉鎖した元データに穴を作っていた。元の面列を照合し、完全に相殺する逆向き面の対を両方除く方法で修復できる。穴埋め・外形の一律変更はしない。sourceVertexIdsで元頂点への対応を保持する。
2. [旧付着の実測集計](validation/v076/source-bones/legacy-attachments.json)では、菱形筋2区分は0/1の固定領域がどちらもなく、三角筋前部・中部、前鋸筋、肩甲挙筋などは停止側の固定領域がない。大胸筋胸肋部以外は片端が欠ける区分が多い。
3. 旧ランドマークと実筋・骨表面の位置ずれを確認。例えば三角筋前部・中部の終端と古い停止候補には長軸方向のずれがあり、8mmの旧候補半径内に入らなかった。筋腹の終端と骨の腱付着を同一視せず、source上の筋／腱終端の推定領域として記録する必要がある。
4. 80回・1%基準値混合のウェイト平滑化は、固定領域を境界条件として解いた調和場ではない。固定端を補った正のグラフLaplacianによるDirichlet解を検証中。両端の根拠がない成分へ新しい骨付着を捏造しない。

## 不採用の実験

- 独立な局所面積／厚み補正：元形状の細い三角形や不整合な材料チャートで悪化。製品へ追加していない。
- 直線ガイドだけへの変更：全体の辺長外れ値を解消できない。
- Rest-surfaceの球面補間／Dual Quaternion／中心回転だけ：形状が滑らかに見えても閉鎖原型の体積が大きく減る姿勢がある。これだけで完成扱いにしない。
- 元表面法線に沿う単一レイの半弦長：長手方向の端面で長すぎる交差となる。組織の実測厚さとは扱わない。
- 全体体積のみのスカラー投影：局所反転や体積の大きい喪失を直せない。根が求まらない状態を閾値緩和や一律の厚み変更で隠していない。

## 文献との照合

[Ganokroj et al. 2022（著者公開PDF）](https://drmillett.com/wp-content/uploads/2023/02/Qualitative-and-Quantitative-anatomy-of-the-humeral-attachment-of-the-pectoralis-major-muscle-and-structures-at-risk.pdf)の方法・図1〜4・表1〜2を確認。広い上腕骨付着、筋腱移行部と骨付着の区別、標本と計測法による差を定義データへ反映する。8男性標本の群平均を、このアトラスの固定寸法として強制しない。本文の骨格・筋・腱の位置関係を、出典を付けた推定領域の照合に使う。

[Kavan et al. 2008](https://users.cs.utah.edu/~ladislav/kavan08geometric/kavan08geometric.html)の幾何学的スキニングと物理変形の違いを確認。回転補間の安定性だけで非圧縮性や解剖学的妥当性の合格にはならない。

## 次の判定

# v0.60.1 — 筋変形の微調整

静止時のBodyParts3Dメッシュ、骨格、肩甲帯運動係数、長押し2方向操作は変更しない。形状の恣意的な縮小を避け、変形ウェイトのみ調整。

前鋸筋・肩甲下筋・広背筋：停止候補への距離に応じた滑らかなウェイト。肋骨/肩甲骨表面近接候補の影響は5–16 mmの有限支持で減衰し、索引の探索範囲外で不連続にならないようにする。停止近傍は競合する起始候補との距離で判断。僧帽筋、大胸筋、三角筋：中間ウェイトを起始側へ偏らせ、端点は保持。全17部位に固定候補を保持する2回の隣接Jacobi平滑化を読み込み時だけ適用する。閾値・指数は調整用であり、文献から測定した係数ではない。

同じメッシュ・同じ姿勢で旧v0.60と新ウェイトの局所辺長比（最大360サンプル/部位）を比較する。0.5–2倍外の辺数と95パーセンタイルを表示。正常範囲・筋束長・筋力・筋体積・衝突判定ではない。新方式が全姿勢で改善する保証はない。前鋸筋の既存放射方向ガードは比較両方に同じ条件で適用。左右別に計測する。

描画時に骨の変換行列を片側ごと再利用。端末の操作中/停止中JS描画呼び出し時間を直近90回記録する。GPU完了時間やFPSではない。実ブラウザGPU描画、iPad実機速度、衝突/接触、臨床精度は未検証。

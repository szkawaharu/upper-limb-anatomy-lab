# v0.57.2 操作性・前方挙上

- BodyParts3D座標はworld -Zが前方。旧肩関節の+Zを修正。模式フォールバックの+Zは保持。
- 挙上面の回転軸を明示して180度近傍の不連続を抑制。肩甲帯前方移動は挙上面に依存する固定係数（実測に基づく値ではない）。SC/AC/GHの共有中心は維持。肩甲胸郭接触未実装。
- 前ならえは左右90度前方挙上、肘伸展、手指伸展。既存手掌法線と前腕軸から回内外角度を探索（5度刻み、上腕軸回旋は±30度以内）。手の読み込み前の姿勢は近似。左右は既存鏡映。T字・バンザイ・基本肢位も両側同時に設定。
- 自動描画：操作中 framebuffer pixel ratio <= 0.85、停止180msまたはpointer releaseで高精細（<=2）へ復帰。CSS座標・メッシュ不変。軽量固定／高精細固定も可。入力をrequestAnimationFrameで集約し終了時に確定。関節操作後の画面外救済はON/OFF可。
- 合成データによる回帰試験。iPadのFPS、実骨の接触、臨床的可動域は未測定。

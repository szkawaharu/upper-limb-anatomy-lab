# v0.73 公開版の既知の問題・再開手順

2026-11-26にユーザーの明示指示で先行公開。未解決という判定は維持し、公開後も下記の修正を続ける。通常チャットへの入口は[HANDOFF_V073.md](../HANDOFF_V073.md)。

## 公開後も残る問題

1. アトラス筋17区分と頸部筋6メッシュには共通写像を実装したが、既存の手作業筋35部品・腱60部品は経路アダプター段階。全材料座標・全付着データへの移行は未完了。
2. 高挙上時の局所辺長変化・腋窩形状がまだ大きい。初回実姿勢監査は最大46.878倍の辺長比を検出した。隣接ウェイトの急変と中心線射影の分岐を診断し、基準メッシュの接続に沿った正則化を追加したが、正則化後も最大16.029倍の辺長比、3°当たり最大53.698mmの頂点変位が残り、正常な形状・連続性を保証する状態には達していない。
3. 胸郭・骨頭の拘束は楕円体／球の基準相対包絡。骨メッシュとの正確な距離・交差、筋間接触、筋膜の滑走、腋窩での三角筋との接触は未実装。反転・交差を未計測のまま0件とは判定しない。
4. 大胸筋3区分・三角筋3区分はクラスタリング後のトポロジーが閉鎖・整合条件を満たさない。体積±5%の合否を算出できない。穴を安易に塞いだ体積や、局所倍率の積だけを正確な体積保存の証明にしない。
5. 頸部の付着領域は高さ・距離からの推定。小菱形筋は既存ウェイトが両骨の0〜1を覆わず、部分付着チャートを用いる。停止領域の解剖照合が必要。特に頸板状筋の複数頸椎への停止、項靱帯、胸鎖乳突筋2頭の付着、肩甲挙筋C1–C4、僧帽筋上部の照合が必要。頸椎軸・中心・椎間板は近似。
6. スマートフォン実機30fps、Safariタッチ、正確な左右鏡映、全手指複合姿勢、弓道4段階の全数値監査は未達。CPU/GPU頂点一致やデスクトップのスクリーンショットで代替できない。
7. 一般の複数頸椎へ分配する起始はCPUで処理する。2骨の混合起始はGPU対応したが、最悪時の負荷は未保証。GPU法線は局所近似で、接触補正後の正確な表面法線と一致しない。
8. 旧版の前鋸筋シェーダー補助関数欠落を修復したため、比較メニューの旧方式は保存版v0.72.0と全く同じGPUフォールバック状態ではない。原版比較には保存ブランチを使用する。

## 再開順序

1. `npm ci && npm test`。`test-results/results.json`とCIを確認。
2. `npm run serve`、`CHROME_PATH=... npm run test:browser`。実アトラスの最大辺長・面積・付着誤差・GPU差・逆方向復帰を再現。中間結果と最終結果を混ぜない。
3. `docs/validation/v073/`の外れ値を起点に、全辺へ起始／停止ウェイト差・材料座標差・lane差・フレーム条件数を出力する。安易な筋別係数追加や閾値緩和をしない。
4. 固定領域と筋腹の遷移を、骨面に照合した境界条件から再構成する。共通座標正則化の反復数・事前値の重みを収束／感度試験で決める。実装中の80反復／1%事前重みは初期工学値。
5. 前腋窩・三角筋に骨メッシュ空間索引を構築し、基準姿勢にある交差と変形で増える交差を分離。接触後の局所変形勾配と体積の両方を評価する。
6. 元STLとクラスタリング後の閉鎖性を比較。体積を測れる表現が必要なら、元閉鎖形状／適切な内部要素を導入し、元の解剖表面を破壊しない。
7. 頸部の骨ローカル付着を照合し、頸板状筋のC1–C3停止、胸骨／鎖骨の分配、椎間板終板の追従を修正。
8. 残る95手作業部品を共通の基準形状・領域定義へ順次移す。従来の手首・指の経由点を廃止して貫通を隠さない。
9. 実機の複合操作と全方向の視覚比較を実施。局所破綻・回帰の解消を確認し、修正版の検証結果を記録してmain／Pagesへ反映する。先行公開したことを形状合格と混同しない。

# v0.76：面の数値判定を座標単位から独立させる

2026-11-27。変形形状や医学的合格基準を変更しない監査の修正。

旧監査は外積の長さが `1e-12 world²` 未満なら退化面とした。この定数は単位変換で判定が変わり、正しい微小な分割面まで退化と扱う。PLC細分の15面では、Float64でもFloat32座標でも実際の面積は非零で、辺の座標一致も0件だった。最小の外積長はFloat64で約1.66e−14 world²。単位だけで無効になり、閉鎖体積の欄が評価不能となっていた。

`triangleQuality` は、入力座標の差、2つの積とその差に由来する保守的なIEEE754丸め誤差を外積の各成分について評価する。少なくとも1成分が誤差上限を超える場合だけ非共線を認め、非有限・共線・不確定な面は引き続き拒否する。固定の絶対面積値を下げて合格させる修正ではない。

旧値以下の面は `smallAbsoluteAreaFaces` に全件残し、旧定数も `legacySmallAreaCutoffWorld2` に出力する。15という診断値は消えない。`precisionPolicy` は新判定の意味を示す。自己交差は別問題であり、`selfIntersectionStatus: not-evaluated`、`physicalVolumeVerified: false` を明示する。閉鎖・向きの整合だけを物理的体積や人体精度の合格にしない。

単体試験は座標倍率1e−12〜1e8での同じ四面体、共線、実際にFloat32座標が一致した三角形、非有限値を検証。全36 Node試験を通過した。0.001mmの平衡停止、1mmの付着誤差目標、閉鎖筋の±5%体積目標、正J条件は緩和していない。

同じ90°外転の接触済み参照をブラウザで再監査し、Float64/Float32とも位相境界0、非多様体0、向き不整合0、不確定・退化0、旧絶対値以下15を確認。体積比は0.999107088 / 0.999107080。画像を変更する修正ではない。これはFloat32で保存した静止形状の検査であり、GPUによる筋変形やスマートフォン30fpsの検証とは区別する。

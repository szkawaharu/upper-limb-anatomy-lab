# v0.49 — 上肢解剖の医学的妥当性監査

更新: 2026-11-23  
目標: **医学部生が自主学習に利用できる正確性**。この目標は現時点で**未達**。v0.49は監査を実装した検証版であり、医学的な認証・教育機関による査読・臨床での利用を意味しない。

## 1. 分離して評価する要素

| 対象 | 現在の状態 | 表示上の扱い |
| --- | --- | --- |
| 起始・停止・神経支配・作用の文章 | NCBI Bookshelfなどの標準解剖学資料を照合 | 出典のある一般的解剖知識。例外や変異あり |
| 上肢5骨・手27骨 | BodyParts3Dの実骨形状データ（読込成功時） | 形状データ。姿勢・関節軸を医学的に検証したことにはならない |
| 筋腹の形状 | 骨座標と制御点から作った推定管状/面状メッシュ | **未検証・教育用の近似** |
| 腱の経路と付着面 | 推定点と単純化した接続・ガイド | **未検証**。滑車・支帯・骨表面での滑走は未再現 |
| 肩・肘・橈尺関節の運動 | 推定軸と簡略運動学 | 骨接触、靱帯拘束、個人差の定量検証が必要 |
| 筋力・収縮による膨隆 | 視覚的な描画係数 | 実測の生理的な収縮率ではない |

## 2. 上腕の必須構造と現実装の差

- 上腕二頭筋：長頭/短頭を模式表示。関節上結節・烏口突起から橈骨粗面への走行は文献で確認できるが、**上腕二頭筋腱膜、長頭腱の結節間溝での滑走、正確な腱停止面は未再現**。
- 上腕筋：上腕骨前面遠位部から尺骨への付着を模式表示。深層の実際の筋腹・腱膜形状の定量評価はない。
- 上腕三頭筋：長頭・外側頭を模式表示。**内側頭の3Dモデルが未実装**。実際は長頭・外側頭・内側頭が共通腱へ合流し肘頭に停止する。
- 烏口腕筋：**未実装**。烏口突起から上腕骨内側面へ。
- 三角筋：3部分を模式表示。形状は未検証。
- 回旋筋腱板：棘上筋・棘下筋・小円筋・肩甲下筋の系統的モデルは**未実装**。
- 腕神経叢、末梢神経、靱帯、関節包、血管：解剖学的全体系としての3D検証はなし。

## 3. 検証の基準（release gates）

P0 — 次の構造追加前に必要
1. 各筋で起始・停止が対応する実骨の解剖学的ランドマークに乗ることを、3D座標と参照画像で第三者が確認する。
2. 深層・表層の関係、骨への貫通、腱の不連続を姿勢ごとに検証する。**端点差 0 mm は解剖学的妥当性の証拠ではない**。
3. 未実装構造を「実装済み」「解剖学的に正確」と表示しない。
4. NCBI等の本文の出典、レビュー日、個体差・例外を明記する。
5. iPhoneの描画/操作テスト。姿勢の再現性と保存版へのロールバックを用意する。

P1 — 医学系の自主学習用に向けて
1. 上腕三頭筋内側頭、烏口腕筋、上腕二頭筋腱膜を実骨ランドマークとともに追加。
2. 回旋筋腱板4筋・肩甲胸郭運動、肩甲上腕リズムの参照モデルを整備。
3. 関節運動・筋腱長・モーメントアームを **OpenSim Upper Extremity Model** 等と姿勢範囲ごとに比較する。
4. 出典・検証用ポーズ・期待値・許容誤差を持つ自動回帰テストを導入する。
5. 可能なら解剖学の専門家による図示・停止面・神経支配のレビューを受ける。

P2 — 将来の力学的妥当性
- 実測パラメータに基づく筋腱経路・滑車・筋張力・関節接触のモデル化。
- 腱膜/靱帯/神経の3D整合性、個体差、医学的応用の可否を別個に評価。

## 5. v0.49で実際に行ったこと

- 出典付きの上腕筋解剖カード（起始/停止/神経支配/作用）を提供。
- 単独表示で実装された筋の近似メッシュのみ観察可能。
- 未実装の三頭筋内側頭・烏口腕筋などを隠さず表示。
- 描画上の「二頭筋のふくらみ」を生理学的測定値と区別。
- **3Dモデルの解剖学的な正確性を証明したわけではない**。

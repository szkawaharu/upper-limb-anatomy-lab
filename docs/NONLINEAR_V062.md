# v0.62 非線形変形と経路近似（研究用）

参考: Kavan et al., Geometric Skinning with Approximate Dual Quaternion Blending, ACM TOG 27(4), 2008 https://users.cs.utah.edu/~ladislav/kavan08geometric/kavan08geometric.html ; OpenSim wrap objects https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090145 ; 前鋸筋の起始・停止 https://www.ncbi.nlm.nih.gov/books/NBK531457/ ; 肩上肢筋 https://www.ncbi.nlm.nih.gov/books/NBK482410/ 。

GPUの線形補間に加え、2剛体変換の正規化デュアルクォータニオン補間を実装。符号反転で同じ半球に揃える。固定ウェイト0/1、中立姿勢、左右鏡映を維持。DQSはねじれでの潰れを軽減するが、膨張・自己交差・体積保存を保証しない。

前鋸筋: 実肋骨の楕円体近似から横断面の無次元半径を求め、中立に対する半径変化を制限。肩甲骨・肋骨の固定候補は維持。三角筋・大胸筋: 上腕骨表面の近位サンプルからGH周囲の近似半径を計算し、中立より深い食い込み候補を抑制。いずれも中間ウェイトに限定し、頂点補正最大0.12モデル単位（約21.6mm）、中立形状不変。不足データ時は新補正なし。これはOpenSimの筋腱中心線のラッピング計算の移植ではなく、表面頂点の近似拘束。肋骨別の真の付着面、個別筋束経路、衝突、筋力、体積保存は未実装。

比較選択: v0.61のウェイトを固定し、線形/DQS/線形＋経路/DQS＋経路を17姿勢のサンプル辺長損失で評価。経路ON/OFFそれぞれで旧線形候補を含める。選択は読み込み時のデータと設定を基準とし、任意姿勢で改善する保証なし。線形モードはv0.61描画、手動DQSモードは経路スイッチに従う。現在姿勢の左右別比較を表示。

DQS用カメラ境界はウェイト区間ごとに中点変換と保守的な半径を使う。経路補正は最大変位分を追加。CPU参照とシェーダの式を対応させたが、実ブラウザGPUコンパイル・iPadの表示と性能・実メッシュの臨床的妥当性は未検証。

読み込み時は姿勢ごとのDQペアを再利用し、経路ON/OFFの候補採点は現在の経路スイッチに依存しないようにする。シェーダの法線は回転近似であり、経路補正後の厳密な再計算ではない。

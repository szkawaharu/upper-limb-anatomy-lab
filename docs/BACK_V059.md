# v0.59 背部筋と付着近似

BodyParts3D / Anatomography (DBCLS), CC BY-SA 2.1 Japan. https://doi.org/10.1093/nar/gkn613 。固定した上流コミットの右僧帽筋上部FMA33586・中部FMA33584・下部FMA33581、右広背筋FMA13358を共有座標で取得。左は鏡映。

参考: https://www.ncbi.nlm.nih.gov/books/NBK531457/ （前鋸筋の肋骨起始・肩甲骨内側縁）; https://www.ncbi.nlm.nih.gov/books/NBK538319/ ; https://www.ncbi.nlm.nih.gov/books/NBK537216/ ; https://www.ncbi.nlm.nih.gov/books/NBK482410/ 。

前鋸筋は右1–9肋骨の実メッシュの表面サンプルを空間索引化し、近接起始候補を静止側に固定。肩甲骨内側縁の推定線を停止候補とする。菱形筋・肩甲挙筋・肩甲下筋も推定付着領域の距離を用いる。前鋸筋の中間頂点には胸郭中心からの放射方向変位を抑えるGPU制約（中間ウェイトで外向き約12 mm、内向き約5 mm、端点では無効）を追加。これは相対変位の抑制で、胸郭の真の表面との接触や貫通防止を保証しない。筋体積保存・筋力・滑走・付着面の厳密検証は未実装。上部僧帽筋は鎖骨追従近似。腰椎・骨盤・頭蓋は未実装。広背筋の下部は静的な元形状のまま。

表層筋は初期OFF、個別切替。実骨WebGL時は旧板状表層筋を描画しない。取得失敗は未取得として表示。前鋸筋・広背筋のみ1.5 mmクラスタリング。既存の両腕操作、軽量描画、骨格を保持。

テストは合成データとCPU参照式によるもの。実機WebGL描画、実際の付着精度、FPSは未確認。

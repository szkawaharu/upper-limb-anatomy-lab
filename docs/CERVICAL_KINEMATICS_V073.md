# v0.73 頭部・頸椎回旋（開発版）

T1 → C7 → C6 → C5 → C4 → C3 → C2 → C1 → C0の階層を実装。既存頸椎7個を最終骨変換で描画し、頭蓋骨はC0へ接続する。下位から累積した回転と、親骨で変換した各関節中心を使用する。頭部全体を頸部一点だけで回転させない。

## 可動域と設定

±75°は教育用操作範囲。`engine/cervical-kinematics.js`に分配・骨ローカル軸・基準関節中心を独立定義した。

|運動節|操作角への分配|
|---|---:|
|C7–T1|2%|
|C6–C7|4%|
|C5–C6|7%|
|C4–C5|8%|
|C3–C4|8%|
|C2–C3|7%|
|C1–C2|60%|
|C0–C1|4%|

合計100%。この比率は実測比率ではない。C1–C2への主要寄与を表す初期の教育用近似である。原著の対象者、全ROM／片側ROM、動作条件の違いを区別し、一研究の平均比率を全姿勢へそのまま適用していない。

関節中心は同じアトラスの椎体／歯突起領域の高さ・座標範囲から推定し、正中面に置く。軸は基準上方を用いた近似であり、個別椎間関節の実測瞬間らせん軸ではない。椎間板は隣接変換の中間姿勢で追従し、両終板の接触や椎間板応力は未再現。屈伸・側屈はAPI上の拡張先のみで操作未実装。

## メッシュとライセンス

元アトラスは全て `2c83c698788cff57f6317bddcf712e7acfbea7d8`。BodyParts3D / Anatomography、© DBCLS、CC BY-SA 2.1 Japanのクレジットを継承。共有mm座標へ同じ`atlasToWorld`変換のみを適用し、個別部位の再中心化や拡大をしない。

頭蓋骨22部品（前頭・後頭・蝶形・側頭左右・頭頂左右・篩骨・下顎・顔面諸骨）と頸部筋6メッシュ（胸鎖乳突筋左右、頭板状筋左右、頸板状筋左右）を部位表とSTLツリーで照合。全28ファイルの長さ・Git blob SHAを実バイナリで確認した。結果は`validation/v073/cervical-source.json`、再現コマンドは`node scripts/verify-cervical-atlas.mjs /path/to/stl`。

## 頸部筋

6メッシュは共通変形エンジンで処理する。胸鎖乳突筋の胸骨／鎖骨側は正中からの距離による推定分配、頭板状筋は頭蓋へ、頸板状筋は暫定C2へ接続。既存肩甲挙筋はC1–C4、僧帽筋上部は後頭〜下位頸椎の高さに応じて起始側を分配できる。

**これらの骨ローカル付着領域は未照合。特に頸板状筋のC1–C3への広い付着、項靱帯と胸骨／鎖骨の各付着は修正が必要。アトラス形状取得成功は付着精度の確認を意味しない。** 斜角筋、頭半棘筋、後頭下筋は追加していない。頭部と頸部筋は取得済み部品を維持して不足部品だけを再取得する。

## 操作

頭部上でpointer-downすると首専用ジェスチャーを開始し、カメラ操作へ渡さない。開始時の角度、カメラyaw、指位置、画面方向の符号を固定する。前・後面では頭部の回旋方向の投影、側面で投影が小さい場合は固定の方向規約を使う。これは深度を含む頭部IKではない。指を止めた入力は同じ角度となり、途中で軸を再解釈しない。

スライダー、角度表示、中立位リセット、頭部／頸部筋の表示切替を追加。首角は左右腕の設定オブジェクトへ格納しない。複数タッチで頭部操作中に別の操作が混ざらないよう捕捉する。実機Safariの指操作と側面での直感性は未検証。

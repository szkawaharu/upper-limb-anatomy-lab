# v0.55 上肢3D解剖ラボ：肩甲骨筋形状の再設計と全体監査

**更新：2026-11-24／対象：右上肢モデル／前版：v0.54（保管ブランチ `archive/v0.54-before-anatomy-rebuild`）**

## 目的と評価条件

開発目標は「医学部生が自主学習で使える正確性」。現時点では**未達**である。骨格はBodyParts3D由来の実骨ポリゴンだが、筋腹・腱は**解剖学的記述に基づく推定座標と、独自の描画アルゴリズム**で生成する。筋の形状を医学的に正しいと保証しない。標準的な起始・停止・作用とモデルの推定範囲を分離する。

### v0.54実機スクリーンショットで確認した問題

- 棘下筋と思われる広い赤い面に**定規で描いたような斜線と直線境界**が残る。
- 棘上筋が細い長方形／帯状で、**筋腹の中央部が膨らむ形・非対称な筋束**が読み取れない。
- 小円筋・大円筋の表示は細くなったが、同じ**直線補間式**を利用するため形態差が乏しい。
- 90°～125°の肩挙上で肩峰・関節周辺の**腱接続が密集・交差して見える**。
- 骨と筋・腱の**接合点最大差0 mm**という診断は数値上の縫合一致であり、解剖学的接触の実証ではない。

## 文献に裏付けられた形態と、v0.55で採用した描画方針

| 筋 | 医学的根拠（基本形態・起始・停止） | 描画方針 | 未検証 |
|---|---|---|---|
| **棘上筋** | 棘上窩から上腕骨大結節上関節面へ、肩峰下を通る。前部と後部では筋束・腱の構造が異なる | **紡錘状寄りの曲面筋腹**、内側～中央を膨らませ外側で徐々に細める。上下の輪郭を別の曲線にする | 前部／後部の実測筋束、肩峰下滑走、関節包・腱への融合 |
| **棘下筋** | 棘下窩を広く占める厚い三角筋。外上方に筋束が集中し中関節面の腱へ | **広く厚い非対称な三角形状**。内側縁・下縁を曲線にし、肩甲骨後面に投影して腱へ収束 | 3亜領域、MRI形状、骨面の筋付着窩分割 |
| **小円筋** | 肩甲骨後面の外側縁に起始し大結節下関節面に停止。細長い筋 | **細く長い弯曲筋腹**、外側縁に沿う。腱への移行を薄くする | 上下2束・関節包との連続・骨面への固定 |
| **大円筋** | 肩甲骨下角後面から結節間溝内側唇へ。厚いが扁平な筋で、**回旋筋腱板には含まない** | 細すぎる円柱ではなく、**一定の幅のある扁平束**。停止側に向かって収束 | 内側唇の正確な位置、広背筋腱との相対関係、筋束形態 |

### 参考資料（実在・閲覧確認）

1. **StatPearls：Supraspinatus Muscle**, NCBI Bookshelf, [NBK537202](https://www.ncbi.nlm.nih.gov/books/NBK537202/) — 棘上窩／大結節上関節面／肩峰下腱の経路。
2. **StatPearls：Infraspinatus Muscle**, [NBK513255](https://www.ncbi.nlm.nih.gov/books/NBK513255/) — 厚い三角形、棘下窩の内側約3/4、外上方へ向かう腱と大結節中関節面。
3. **StatPearls：Teres Minor**, [NBK513324](https://www.ncbi.nlm.nih.gov/books/NBK513324/) — 外側縁から大結節下部へ向かう細い筋。
4. **StatPearls：Teres Major**, [NBK580487](https://www.ncbi.nlm.nih.gov/books/NBK580487/) — 下角後面から結節間溝内側唇へ、扁平な筋。
5. **Subregions of the Rotator Cuff Muscles Present Distinct Anatomy, Biomechanics, and Function** (review, 2025), [PMC11679125](https://pmc.ncbi.nlm.nih.gov/articles/PMC11679125/) — 棘上筋の前後・深浅の差、棘下筋3亜領域、小円筋の複雑な腱停止。
6. **Muscle Architecture Properties of the Deep Region of the Supraspinatus: A Cadaveric Study** (2024), [PMC11483794](https://pmc.ncbi.nlm.nih.gov/articles/PMC11483794/) — 棘上筋深部の筋束方向や筋形態の個体差。
7. **Assessment of the supraspinatus muscle fiber architecture with diffusion tensor imaging** (2024), [PMC11464712](https://pmc.ncbi.nlm.nih.gov/articles/PMC11464712/) — MRI拡散画像による筋束構築の検討。
8. **US anatomy of the shoulder: Pictorial essay**, [PMC3553044](https://pmc.ncbi.nlm.nih.gov/articles/PMC3553044/) — 腱や肩峰との臨床解剖学的位置関係。
9. **BodyParts3D**, [repository](https://github.com/Kevin-Mattheus-Moerman/BodyParts3D), [original database and attribution](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/20100816/README_e.html), [original research DOI](https://doi.org/10.1093/nar/gkn613) — 骨格STL。**CC BY-SA 2.1 Japan**表記を維持。

**文献の形態記述は実証された一般的知見だが、v0.55で選んだ曲率係数・厚み係数・停止の3D数値は文献で測定された値ではない。** 定量的な形態一致を主張しない。

## 実装仕様の変更

- `SCAPULAR_FORM_V055`：筋別に「内側端幅・筋腹中央幅・外側端幅・上下縁の曲がり・厚み・中央筋束のずれ」を定義。4筋で異なる輪郭。
- `scapularCurvedAtlasPoint(spec,s,u)`：従来の直線補間から、**異なる曲率の2本の輪郭線＋非線形な幅分布**へ変更。端部は既存の骨面付着近似点に一致させる。
- `SCAPULAR_STATIONS_V055`／`SCAPULAR_LANES_V055`：17断面×11列（v0.54は12断面×7列）。極端な平面感を減らす。
- 筋腹の厚みは縦・横の双方で**周縁から中央に向かって緩やかに増加**。骨の後面に薄く接する下側も維持。
- 腱は起点から停止までの**凸結合の二次曲線**。筋腹との接合断面は両パーツで共有する。旧版の急な押し出し球ガイドは引き続き使用しない。
- **レントゲン・MRIの実物ポリゴンによるフィットではない**。筋線維の高精度な再現・筋肉の体積保存・腱の曲げ剛性・関節包衝突は未実装。
- UIに各筋の起始・停止と形態資料リンク、および推定3D形状である注意書きを追加。単独表示・骨の半透明・回旋筋腱板3筋表示を維持。
- `window.__labScapular()` の診断に4筋の幅の推移・形状分類と腱の最大制御点ステップを追加。

## 自動検証と限界

```sh
node tests/scapular-muscles-v055.mjs
node tests/scapular-muscles-v054.mjs
node tests/scapular-muscles-v053.mjs
node tests/scapular-muscles-v051.mjs
node tests/medical-anatomy-audit.mjs
node tests/shoulder-kinematics-v050.mjs
```

- 最新テストは**7挙上角×5軸回旋＝35姿勢×4筋**を生成。後面への正の投影クリアランス、筋腱接合点、筋ごとの横幅・輪郭曲率、停止部の上腕骨への追従、ON/OFF後の古いジオメトリ削除を検査。
- 生成した筋腹・腱の閉曲面について、全頂点の有限性、三角形の非退化、各稜線の出現回数＝2（閉じたマニフォールドの**局所的構造**）を検査。
- 旧版の合成テストおよび**既存の肩帯運動126条件**を回帰。
- **重要**：これらは合成骨面の幾何学テストであり、**実際のBodyParts3D肩甲骨の3D筋付着領域検証、骨間衝突、腱滑走、医学専門家レビューの代用ではない**。iPhone上の最終視覚チェックも別途必要。
- 肩の「挙上角の1/3だけ肩甲骨回旋」という同期は**固定値の模式運動学**。肩甲上腕リズムの実測的精度はない。

### 医学部自習レベルまで残るP0項目

**P0**: 上腕骨大結節（上・中・下関節面）と結節間溝の停止領域を実骨メッシュ上に同定／棘上窩・棘下窩・外側縁・下角の起始領域を適切に抽出／筋・腱と骨の3D交差・包含・距離を可視化／0°・45°・90°・125°挙上などの専門家照合。

**P1**: 肩甲下筋追加（典拠付きの小結節停止）／筋束方向と解剖層・腱板融合の表示／実測範囲に基づく肩甲上腕リズム。

**P2**: 個体差モデル、MRI/CTからの形状比較、筋腱力学・筋収縮量の較正、左右上肢。

**結論**：v0.55は**解剖学を参考にした視覚的改善**。医学生向けの資料として正確性を保証できる段階ではない。判定には骨面・筋・腱の実測照合と専門家レビューが必要。

# v0.53 肩甲骨後面筋の形状修正・検証記録

更新日：2026-11-24  
対象：上肢3D解剖ラボ、棘上筋・棘下筋・小円筋・大円筋  
開発上の目標：**医学部生が自習に使える解剖学的正確性**  
**現在の判定：未達。** 名称・一般的な起始停止・作用は典拠に沿うが、**3D付着面と腱の走行は未検証の近似**。

## v0.51の実機スクリーンショットから読み取れた問題

- 肩甲骨の表裏をまたいで赤色の筋肉が斑点状に見える。旧メッシュは幅のある薄板を骨面に重ね、中央から前後に厚さを付けていたため、下面が骨を横切り得た。
- 棘下筋などが矩形に近い硬い薄板として見え、筋腹の丸み・周縁の漸減が不足。
- 腱が関節近くを一直線に通り、上腕骨頭を避ける経路として不十分。
- 旧方式は2D投影点の近隣骨頂点から背側寄り1点を選ぶだけで、骨面三角形の連続性を扱わなかった。

## v0.53で実際に修正したこと

1. **実骨メッシュの三角形に対する後面レイ投影**：BodyParts3Dの肩甲骨三角形を座標インデックス化し、骨の前後2面のうち観察上の背側（上部のZ値）を選択。投影できない位置は骨の最近傍境界頂点に丸め、**その件数を表示して注意喚起**する。
2. **筋腹のレンズ状断面**：筋の端を薄く、中央を厚くした扇状の閉じたメッシュへ。筋腹下面に骨後面から正の微小余裕を与え、旧版の板状の周縁・赤い突き抜けを軽減する。
3. **肩甲骨・上腕骨の別座標追従**：筋の骨盤側起始と上腕骨側停止はそれぞれの骨の変換に追従。片方の骨の姿勢に固定しない。
4. **腱の緩やかな弧と骨頭の仮想回避ガイド**：上腕骨頭の周囲を直線的に横断しにくいよう、**測定されていない球近似**を使う視覚的な回避経路を追加。**実骨面の衝突判定・滑走力学ではない**。
5. **UIの診断表示**：筋腹と腱の接合点差（数学的連続性）、肩甲骨後面投影の近似余裕、投影範囲外の点数を確認可能に。あくまで数値・投影診断であり「医学的適合性」を示さない。
6. **版の保存**：v0.51は `archive/v0.51-before-scapular-fix` に保存。v0.52は作成せず、ユーザーの指定によりv0.53で更新。

- `node tests/scapular-muscles-v051.mjs`：旧来の合成モデルでも落ちないことを確認する後方互換テスト。

**合成テスト成功≠医学解剖学的妥当性の証明。** 今回のテストは、実骨STLの全姿勢・全ポリゴンを用いた骨衝突解析やiPhoneでの最終視認テストを代替しない。

## 残存する重要課題（次の版以降）

- 広範な後面投影は、**最大Z＝必ず正確な筋付着窩**を意味しない。肩甲棘などの突出部や輪郭外に到達した場合の領域限定が必要。
- 棘上窩／棘下窩／外側縁の骨標識点、上腕骨大結節の上・中・下関節面、結節間溝内側唇の**実測に基づく面**との照合が必要。
- 関節包・肩峰・肩甲棘・上腕骨頭に対する腱の実形状・巻き付き・滑走は未実装。球近似は仮表示にすぎない。
- 肩甲下筋は依然3D未実装。回旋筋腱板を4筋揃えた学習モデルではない。
- 棘下筋の筋束ごとの差異、筋体積保存、張力・収縮モデル、患者間変異・正常可動域、解剖専門家レビュー未実装。
- バージョンラベル・単体テストだけで「医学部生に使える正確さ」は保証しない。実骨形状での全方向表示と典拠対照図を用いた監査が最優先。

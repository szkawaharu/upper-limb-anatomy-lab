# v0.76 実骨面の監査と拘束の追加

2026-11-27。作業ブランチ内の修正。筋の形状・体積が未達のため、まだmain／Pagesへ反映していない。

## 原因

従来の胸郭断面loftは肋骨の外形をすべて包む面ではなかった。近似面の62サンプルが正でも、実骨メッシュでは肩甲骨が肋骨内部へ入った。修正前21姿勢では最大5.108mm、基本肢位では0頂点。共有SC/AC/GHピボットの一致だけでは防げない。

## 修正した構造

- 同じ固定コミットの左右全肋骨377,900頂点から162方向の支持平面を生成。すべての元の肋骨三角形を含む凸の包絡を使う。骨寸法・関節可動域・筋厚みを変更していない。
- 支持値のlog-mean-expは最大支持値以下になるため、非負なら元の骨から分離する。これはユークリッド距離や筋膜の実測厚さではない。
- 滑走の法線は各姿勢の文献priorで評価した接平面から求め、関節の反復中は固定する。凸関数の接平面は関数以下なので、保守的な分離条件となる。反復中に別の包絡面へ切り替えることで生じる局所解の不安定さを避ける。
- 肩甲骨全体の6mmセル代表987点を追加。原型の最小支持値は0.629mmで、基準骨位置を動かさず適用できる。
- SC→AC→GHの剛体接続を維持して関節パラメータを解く。目的関数が増える更新はバックトラックし、48反復を参照とする。0.1mmは数値残差の尺度であり、実測の組織厚さ・正常範囲ではない。
- 非一様のC1関節補間へ変更。1mmを超えたセルだけ節点を追加し、基準を緩めず再検証する。最終1,408節点、11,907検証点、剛体点誤差の保守的上限最大0.9671mm。参照コード・依存ファイルのSHA256を保存。
- 付着ウェイトは、旧13姿勢の動的選択から独立した基準データへ分離。旧方式は比較用に残す。これは解剖学的に正しい付着を新たに実測したことを意味しない。

## 実骨による検証

[生データ](validation/v076/source-bones/field-1deg-sweep.json)：外転・肩甲骨面・前方挙上を各0〜180°、1°刻みの543姿勢。各姿勢で肩甲骨元メッシュ56,630頂点を閉鎖した実肋骨メッシュに対して内外判定した。内部頂点0、内部深さ0mm。

[21姿勢の表面検査](validation/v076/source-bones/after-surfaces-and-edges.json)：肩甲骨辺→肋骨面と肋骨辺→肩甲骨面の双方の有限線分交差0件。共面重なりは未分類。肩甲骨・上腕骨・鎖骨の全関節面、軟骨、筋肉同士の接触が合格した結果ではない。

33本のオフライン回帰試験を実行し通過。診断APIは操作キューを確定してから最終骨姿勢を返し、追加拘束の支持値を実骨距離と区別する。新しい外れ値監査は最大辺の頂点ペア・最大面積の三角形IDと元の物理寸法も返す。

## 残る限界

凸包絡は肋間の凹みを含めて包む幾何学近似であり、真の肩甲胸郭接触・生理学的可動域・臨床精度を保証しない。文献範囲外の高挙上は引き続き未検証。スマートフォン実機fpsは未測定。筋変形の完了判断は別に行う。

48対96反復の184姿勢比較で剛体点差の保守的上限は最大0.0000142mm。Nodeでの関節補間の中央値0.090ms、CPU参照83.2ms。描画fps・スマートフォン実測値ではない。
